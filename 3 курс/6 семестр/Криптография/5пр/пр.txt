Пусть есть два о.т. таких, что x_1 и x_2 = (a*x_1 + b) mod N_1, e = 3. Тогда, имеем систему: 

y_1 = (x^e)_1 mod N
y_2 = (x^e)_2 mod N = (a*x_1 + b)^e mod N
Покажем, что в таком случае значения x_1 можно вычислить по известным y_1,y_2,a,b,N.

y_2 = (a*x_1 + b)^3 mod N = (a^3*x_1^3 + 3*a^2*x_1^2*b + 3*a*x_1*b^2 + b^3) mod N
y_2 + 2*a^3*x_1^3 + b^3 = 3*a*x_1*(a^2*x_1^2 + a * x_1 * b + b^2) mod N
y_2 - a^3 * x_1^3 + 2*b^3 = 3*b * (a^2 * x_1^2 + a*x_1*b + b^2) mod N

y_2 + 2*a^3 - b^3            a*x_1
------------------------- = ------- mod N
y_2 - a^3 * x_1^3 + 2*b^3      b
